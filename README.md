# Règles de Confidentialité - Application 9OUM

Cette politique de confidentialité décrit comment l'application **9OUM** collecte, utilise et partage les données utilisateur dans le cadre de la mise en relation entre demandeurs d'emploi, chercheurs de services ménagers et artisans.

## 1. Collecte des données
Nous collectons les informations nécessaires au bon fonctionnement du service :
* Informations de profil (Nom, prénom, numéro de téléphone, adresse email).
* Données de localisation (pour afficher les artisans et offres d'emploi à proximité).
* Photos de profil ou de réalisations professionnelles.

## 2. Utilisation des données
Les données collectées sont utilisées exclusivement pour :
* Permettre la mise en relation et la communication entre les utilisateurs.
* Améliorer l'expérience utilisateur et la sécurité de l'application.

## 3. Partage des données
Nous ne vendons ni ne partageons vos données personnelles avec des tiers à des fins commerciales. Vos coordonnées professionnelles (téléphone, prénom) ne sont visibles qu'aux utilisateurs de la plateforme dans le but de faciliter le travail et la prestation de services.

## 4. Droits des utilisateurs
Vous pouvez à tout moment modifier ou supprimer vos données personnelles directement depuis les paramètres de votre compte dans l'application.

## 5. Sécurité
Nous mettons en œuvre toutes les mesures de sécurité nécessaires pour protéger vos informations contre tout accès non autorisé.
